# Mindmaven Executive OS

Claude skills for executives and their EAs: prebriefs, debriefs, morning scans, loop leverage, eDrafts, daily calendar upkeep, an end-of-day update, and a Friday calendar review. Each skill is its own plugin, so you can add only the ones you want and get updates without re-downloading anything.

## Install (Claude desktop app or claude.ai)

1. Open **Customize** in the left sidebar, then **Plugins**.
2. Click **Add**, then **Add marketplace**, and paste this repository's address.
3. Open the **Discover** tab. Install **mm-setup** first, then the skills you want.
4. Turn on **Sync automatically** for this marketplace so you get updates on their own (or click **Check for updates** when your coach tells you there's a new version).
5. Open a new chat and type: **Set up my executive OS.**

Questions: your Mindmaven coach.

This repository is generated by `build.ps1` in the Executive OS source folder. Don't edit it by hand.
